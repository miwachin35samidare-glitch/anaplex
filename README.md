# AnaPlex: An Architecture for Real-Time Learning

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.21742797.svg)](https://doi.org/10.5281/zenodo.21742797)

**凍結素子と可塑配線による、Transformer後継アーキテクチャの設計**

Transformerはリアルタイム学習ができない。推論中に重みが変わらないからである。
AnaPlexは、**素子を凍結し、配線だけを可塑にする**という解を提案する。

> **Ana** — 4次元方向の「上」を指す語（Hinton, 1888）。3次元の up/down に対して、次元を一つ上がる方向。
> **Plexus** — 神経叢。神経が集まって網目状に絡む部位。
>
> 素子と配線は一つの層にある。何かが立ち上がるとしたら、それは網の上の次元にある。

---

## 設計の骨格

| | |
|---|---|
| **素子** | 小型モデルを多数。型を焼いて**凍結**。学習しない |
| **配線** | シナプス = (src, dst, 型ID, 強度)。生えて刈られる。**ここだけが可塑** |
| **学習信号** | 予測誤差のみ。**報酬関数なし** |
| **評価** | 二相プロトコル。内在相では測定しない |

設計は既存研究の組み合わせではなく、神経系の3つの非対称性から導出されている。

1. **ゲノムは重みを書けない**（情報量が6桁足りない）。遺伝が指定するのは細胞種と配線規則だけ
2. **皮質は一様**。モダリティは素子の中ではなく、何が繋がっているかで決まる
3. **記憶はニューロンではなくシナプスにある**。その比は 1:1000

## 最も検証の価値がある点

設計中で最も不確実な部分。詳細は[設計文書 §8](./AnaPlex.md#8-未検証点)。

- **10⁵パラメータの素子で統語が立つか** — TinyStoriesの下限を下回るため、素子から統語を借りられない。配線の創発に賭けることになる
- **表現力の下限** — 素子が入力の違いを区別できなければ、配線が何を強めても差が出ない。「安定している」と「何も学習できていない」はログ上で似て見える
- **快不快が創発するか** — 予測誤差は符号を持たない。外から符号を与えると報酬関数に戻るため、与えない
- **多体での分化** — 「配線が分化を作る」に賭けている
- **配線マージ** — 別々の経験で育った疎グラフを統合できるか。直接の先行が見つからない
- **統語の測り方** — 記号的形式を前提としない定義が必要。この問題設定自体が最近始まったばかり
