# 設計案 版97：続けて流す暮らし（10-24【み】「続けて」）

網は版96 と同じ。変えたのは網の外の回し方だけ（新しい life.py）⇒ 版96 の state.pt はそのまま読める（SAME_NET = (96,)）

## 1 口は毎歩読む
- 毎歩、運動の領野の表現の発火を筋の形（mouth.muscle_force と同じ2次の式。20の細かい歩を前もって 3×3 の掛け算1つに）でならす
- モーラの層の力が READ_TH を越えた歩で mouth.decode して声を鳴らす。自分の声が鳴っている間は読まない（鳴り終われば又読む）
- 合図の外で出た声は「自発」に数える。合図への声に数えるのは、補助輪の指令が入り始めてから（GO_LEAD − CMD_LEAD 歩目以降）の最初の声だけ（⚠️ 下の §4）

## 2 時は止まらない
- 合図（補足への go）は指数の間で入る。平均は人の乳児の発声の頻度 1分に約 4.5回 ⇒ 約 1,250歩（10.67ms/歩）
  人の発声の間は裾が長く群れる（続く間どうしの相関 0.26、Ritwika 2025）⇒ 形は網全体で合わせるときに
- 補助輪の指令は声の CMD_LEAD 歩前から声の終わりまで。声が出なければ GO_LEAD + CMD_LEAD 歩で足場を閉じる
- 耳の音は強さ（パワー）で足す：log(Σ(exp(mel) − EPS) + EPS)。自分・返し手・録音が重なればそのまま重なって聞こえる

## 3 返し手と録音
- 返し手は口が出したどの声にも同じ割合・同じ遅れ（REPLY_CUM、声の終わりから）で返す（voice.Replier.answer_to）
- 録音：口が出した声を最後の 50個まで取っておく。健診（health、学ばない）では2回以上前の録音をでたらめに鳴らす
- 健診の誤差は、1つの種類だけが鳴っている歩だけで数える（重なった歩は数えない）。物差しは版96 までの measure と同じ

## 4 ⚠️ 人の値でなく私が置いた所（見直し待ち・指示を仰ぐ）
- 合図への声に数える区切り（指令が入り始めてから）：数え方だけで網は変わらない
- 録音を鳴らす頻度（健診で 1歩あたり 1/1,250）・2回以上前・50個：健診の形だけで、学ぶ時は鳴らさない
- 暮らしの時計（t・次の合図）は保存しない：指数の間は記憶が無いので、読み直しても間の分布は変わらない
