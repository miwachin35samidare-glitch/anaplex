## 切り分けの結果（09-26 午後。diag_rep.py）

**コードで確かめたこと（版35 の torch_group2.py）**

```
表現のニューロンも、誤差のニューロンと同じ誤差でシナプスを学ぶ（的は下から越え x_t、Δw ＝ η(x_t − p)）
その同じシナプスの合計 exc を、細胞体の駆動にも使う：撃つ ＝ (exc ＋ 下から × 重さ) ÷ (1 ＋ 抑制) ＞ 閾値
興奮性の重みは負になれる（抑制だけ 0 で切っている）
⇒ exc は「予測（樹状突起の側）」と「駆動（細胞体の側）」の2役を兼ねている
```

**最小構成で測った**（聴覚1領野・40帯・相手500。下から越えるのは 1歩 約1%。9本以上で越える、版29 の値）
⚠️ 素子の見込み（prior）は焼いたものではなく代役（コンテナに prior_v1.npz が無い）

```
                      下から撃てた割合（下から越えた歩のうち）      興奮の合計   抑制の合計
                      2000歩   6000歩   10000歩                  10000歩     10000歩
そのまま               15.7%    5.2%     4.2%                    −5.9        0.36
抑制の学びを止める      16.2%    6.4%     7.8%                    −4.8        0.06
恒常性を止める         15.7%    4.7%     4.3%                    −5.9        0.35
見込みを的の率に        94.3%   68.7%    69.8%                    +0.88       0.13
（学ぶ前は 100%：重み 0 なら 9本 × 1.68 ＝ 15.1 ＞ 14.3）
興奮の重みのうち負のもの：そのまま 94%
```

⇒ **主因は、表現のニューロンの興奮の合計が負に学ばれて、駆動を削ること**（抑制の学び・恒常性を止めても変わらない）
   的（下から越え）はまれなので、予測 p を下げるために exc が負へ押される。その exc が細胞体の駆動に足される
⇒ 午前の見立て「育ち続ける抑制」は、この最小構成では主因ではない（抑制の重みは 10000歩で平均 0.015）
   ⚠️ 見込みを的の率に寄せた条件でも 94% → 70% に下がる。抑制の育ちと負の興奮の両方が少しずつ効いている

                     ⇒ ここで、学んだ予測の合計が細胞体の駆動に入った
