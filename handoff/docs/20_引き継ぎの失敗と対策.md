AnaPlex2〜18 と今日のスレッドの頭（引き継ぎ → 失敗 → 復帰）を読んで拾った。
⚠️ 新ラインの始まりのスレッド（09-11〜22）は安全装置で中身が隠れていて読めない。
⚠️ 各スレッドは頭と検索で当たった所だけ読んだ。全部は読んでいない。

## 2. 原因（7つに分かれる）

```
原因1  出どころが残らない
       結論だけ残り、「誰の案か（みわの言葉／Claude の案をみわが選んだ／人の測定）」と「根拠の種」が落ちる
       ⇒ 次の Claude は Claude の案を土台として扱う（09-26、AnaPlex7、10-01）

原因2  落とした案が、その論点の所に残らない
       落ちた手は「Claude の振る舞い」の記録で、「この論点で落とした設計」の記録ではない
       ⇒ 同じ議論が入口で止まらない（134・割り算・区画・切り詰め・Verhoog）

原因3  覆った決めが、元の行で古いまま読まれる
       時系列で積む資料は、後ろで覆っても前の行が残る。⟲ の付け忘れで古い値が ✅ のまま
       ⇒ AnaPlex10・13・09-26

原因4  資料本体が直らない（書き戻し・差分・上げ直し漏れ・作業場所の消失）
       スレッドの終わりにまとめて書く、みわが上げ直す、の2段があり、どちらかで漏れる
       ⇒ AnaPlex4・9・13・15、09-26（outputs が空になった）

原因5  引き継ぎ書・要約を正として読む
       引き継ぎは前の Claude の解釈。そこに誤りや未承認の手が入ると、そのまま次へ渡る
       ⇒ AnaPlex14・15・16・09-26

原因6  確かめる前に言う・出す
       「無い」を探す前に言う／見立てを「人の形」と言い切る／案の部品を確かめずに出す
       ⇒ AnaPlex13・14・09-26・10-01

原因7  1つのスレッドが長く、後半で前半の決めを落とす
       スレッドの中でも同じ取り違えが起き、それが引き継ぎに入る
```

## 3. 対策（原因に対応させる）

```
原因1 ⇒ 決めの行に出どころの印を付ける（印は 00_はじめに.md §3）。印の無い行は「出どころ未確認」として扱う
         過去の判断を持ち出すときは、印を見て言葉のまま引く
原因2 ⇒ 論点ごとの台帳を作り、各論点に「落とした案と理由」を置く。その論点に触る前に必ず読む
原因3 ⇒ 論点台帳は「いまの形」だけを書き換えて持つ。覆ったら古い形は「落とした案」へ移す
         時系列の記録（決まったこと.md・設計案_脳幹.md）は記録として残し、判断の根拠には論点台帳を使う
原因4 ⇒ 資料は Claude がプロジェクトの claude/ に直接書く（09-26 からスレッドをまたいで見える）
         スレッドの終わりにまとめて書かない。確定した時点でその論点の所を書き換える
         みわの上げ直しが要るのは、arkhe で動かすコードだけ
原因5 ⇒ 現在地のファイルは短く、事実だけ（コードの版・最後に測ったもの・次の問い）
         次の問いには「この問いが乗っている決めとその出どころ」を書く。乗っている決めが Claude の案なら、そう書く
原因6 ⇒ 案を出す前に4つを書く（00_はじめに.md §4）
         埋まらないものがあれば案として出さず、「ここが埋まっていない」と言う
原因7 ⇒ スレッドを論点で区切る。論点が変わる所で、その論点の台帳を書き換えてから次へ
```

## 4. 限界（対策でも残るもの）

```
次の Claude が読むのは記録で、記憶ではない。読まずに進めば同じことが起きる
印を付けるのも Claude なので、付け間違いは起きる。印の誤りを見つけたら、その場で直す
```
