## 2 ゴール1（聞き分け）

```
聴覚の誤差（音のある歩 1歩あたり）自分 ／ 録音 ／ 返し手
  録音 ÷ 自分 ＞ 1（向きだけ）  【ヒト】大人で話すと聴覚の応答が下がる。乳児の値は無い
    目安（10-09 に調べた【C の当てはめ】）：上側頭回の高γ 聞く 62.1 ÷ 話す 29.8 ≒ 2.1（Ozker 2024）／ M100 1 ÷ (1 − 0.20〜0.65) ≒ 1.25〜2.9
    ⚠️ 人の値は録音の再生（＝ 抑えない）を基準に、話している声がどれだけ下がるか。場所でばらつき大
  返し手 ÷ 自分 ＞ 1            他人の声も人は抑えない（録音と同じ扱い）。予測できる並びでも応答は主に音で決まる（Leonard 2015、分散の約5%）
測り方  録音は2回以上前に言った自分の声からでたらめに1つ。返し手と録音の順もでたらめ（【み】10-07「5回前固定だと予想できる」）
  ⟲ 10-09【み】「赤ちゃんが録音を延々と聞かされる状況って現実には無い」⇒ 暮らしは 自分＋返し手、録音は10回ごとに3つの試し（measure_v53f）。
     健診は measure_check2.py（暮らし＝自分＋返し手・録音は試し・学びは止めない）
⚠️ 模型の耳は録音と全く同じ音を聞く（人は骨からも聞く）⇒ 自分と録音の差は写しと蹴りからしか出ない（【み】10-07）
```

## 3 揃って撃つ

```
目標  覚醒で γ の位相に揃う細胞 RS 9%・FS 13%（【ヒト】Le Van Quyen 2016、中側頭回）【み】10-07「一旦これで」
模型の当てはめ【C】：細胞ごとに「自分の発火」と「同じ領野のほかの体の同じ歩の発火数」の重なりが、前後 3〜12歩ずらした
  どれよりも多い細胞の割合（10発以上撃った体のうち）。近くのずらしに限るのは、音のある・なしで一緒に上下する分を除くため
  ⚠️ 1歩 10.67ms では γ（1周期 20〜33ms ＝ 2〜3歩）の位相は測れない。測っている量は人と同じではない
1歩に撃った割合の最大・上位1%：人の値なし（参考）
  人で「領野の大半が同じ 10ms に撃つ」は、眠りでも発火でも見つかっていない（発作でもばらばら：Truccolo 2011）
  海馬のリップル（主に眠り）錐体 3.1 → 16Hz ＝ 1歩 約17%（眠りの海馬の欄にだけ使う）
⟲ 前の案「表現 40%超の歩 0」は【C】の基準で取り下げ（10-07）
```
