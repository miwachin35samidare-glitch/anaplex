## 3 A：Brain.step の入口の組み立て（グラフの外、優先）【コード 版114 torch_brain 2315〜2526】

今の形：下からの線の表（287本の道）が道ごとの結果 _bo を返し、受け手の領野ごとに手で足して（`_bo[a] + _bo[b] + …`・`_s103(nm)` は 169本の道の一覧を受け手ごとに回して 0 から足す・`sum(…, torch.zeros(n))`）77領野ぶん torch.cat する。樹状突起の側（e）も同じ形

- A1【C】対応表で1回に：道ごとに「受け手の領野の x の中の位置」と倍率（X_KEEP の X_NEW）を、組むときに道の一覧（道の受け手）から作る。表の結果をその位置へ1回で足し込む（受け手の体ごとに並べて足すので、少ない箱への足し込みにならない）。道でないもの（dg・目・運動前野・合図・PPN→CL ほか）は今の位置に置く
  - 道を足すときは一覧に載せるだけで位置が決まる ⇒ 数値合わせで線・本数を変えても作り直しは自動
  - 確かめ：容器で 40歩、x・e を毎歩 版114 の組み立てと並べて差（丸めの範囲）・発火 違い 0
- A2【C】torch.compile で組み立てをまとめる：コードはほぼそのまま（足す順も同じ）。⚠️ 初めの歩の compile の時間（守り 0.5秒）・ROCm での compile の揺れ・合図（cue_t）など Python の分かれは外に出す要がある
