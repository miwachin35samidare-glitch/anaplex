## 3. 作業の進め方

```
最小構成で原因を分ける
  例：素子 v0 が落ちたとき、持ち方を差し替える／関係を固定する、の2つの診断で
      「素子ではなくテストの立て方が原因」と分けた
組み上がる前に回さない
症状に対して機構を足さない
  例：素子 v1 で乱数の列が悪化したとき、機構は足さず、学ぶ速さが原因と分けた
確定した瞬間に資料へ書く
決まったこと と 案 を分けて書く（案には「⚠️ Claude の案（未確認）」）
実績 と 予想線 を分けて書く（先行研究で確かめられた範囲を越えたら予想線）
見立ては「確かめていない」と書く
調べる前に、過去スレッド（conversation_search）と前の作りの台帳番号（生-2xx など）を先に見る
  前の作りで調べて警告まで書いてあったことを、見ずに調べ直して逆の結論を出した（09-26）

設計が人と違うと分かったら直す。ただし人から離れる直し方はみわに聞く
  「人と同じ」はそのまま進めてよい。「生物と同じ（人以外）」は判断が変わる（みわ 09-26）

  素子は2区画のデフォルメ（樹状突起＝予測、細胞体＝実際、素子の中で比べる）。
  誤差のニューロンに来る興奮性シナプスは予測の入力で、細胞体の EPSP と同じ物差しで比べない
  ⇒ 比べるのは働き（例：【ヒト】上側頭回の細胞は自分の声で撃たなくなる）
  部品を人の細胞1個そのものに寄せる直しは、デフォルメを外す方向。まず働きで人と合っているかを見る

```
