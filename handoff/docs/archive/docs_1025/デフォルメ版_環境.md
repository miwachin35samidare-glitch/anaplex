## 2. PyTorch / ROCm — 踏んだ罠

```
PyTorch 2.13.0+rocm7.2 / HIP 7.2.53211 で動作確認済み（2026-08-02）
```

⚠️ **gfx1201 は ROCm 6.3 に入っていない。**RDNA4 の正式サポートは ROCm 7.2 から。
`--index-url https://download.pytorch.org/whl/rocm7.2` を使う。
6.3 のホイールを入れるとインストールは成功するが `is_available()` が False になる。

⚠️ **`render` グループが必須。**`/dev/kfd` は `root:render` の 660。
`sudo usermod -aG render,video $USER` してから再ログイン。

⚠️ **6.2GB のホイールは pip 直だと途中で切れる。**`wget -c` で落としてローカル指定し、
依存は `--extra-index-url` で拾わせる。依存パッケージ名は 7.2 系では `triton-rocm`
（6.3 系の `pytorch-triton-rocm` とは別物）。

⚠️ `amdgpu-install` は `linuxmint` を弾く可能性があるが、pip 版 PyTorch は ROCm ランタイムを
同梱するので通す必要がなかった。

⚠️ LM Studio が GPU で動くことは ROCm の動作証明にならない（Vulkan バックエンドを持つため）。

⚠️ flash-attention 等は Composable Kernel が CDNA(Wave64) 向けなので Triton バックエンドに切り替え
（`triton-rocm 3.7.1` が同梱）。

```
torch.binomial            ✅ ROCm で動く
torch._standard_gamma     ✅ ROCm で動く
```

🔴 **毎歩 `float()` で GPU から値を取り出すと 1.4〜1.5倍 遅くなる。**
GPU から値を取り出す操作は、毎歩ではなく1回だけにする。

⚠️ **実時間 = 歩数 × 1歩の時間。**GPU の並列は1歩の「幅」には効くが、
歩の「数」は減らせない（状態は前の歩から決まるので順番にしか進めない）。

```
          機械学習に関する禁止条項なし。教育・研究目的は「許可無くやってよいこと」に明記。
          個人利用は許諾不要（法人のみ要許諾）
          → 経緯は `VOICEVOX話者_機械学習可否_20260802.md`
```

🔴 **バージョンと話者を固定する。`latest` タグを使わない。**
ENGINE のバージョンが変わると、同じ AudioQuery から違う波形が出る。
口の（指令 → 音）の写像が途中で書き換わると、積んだものが全部ずれる。

⚠️ **CPU 配分。**ENGINE は合成中に 8コアを飽和（793%）し、CPU 温度 78℃。
80℃ を下回る運用にするため `docker update --cpus=7 anaplex_voicevox` で 7コアに制限。
合成は 0.135s → 0.15s 程度に伸びる。

✅ **デスクトップとの同居は問題ない。**音声は HTTP レスポンスのバイト列としてのみ流れ、
PulseAudio / ALSA を一度も経由しない。ブラウザや通話アプリの音とは混ざりようがない。

### 合成レイテンシ（2026-08-02 実測）

```
対象  3モーラ「ばばば」（実音 0.696s）
前後無音 0.1s ずつ（既定）   0.240s   実時間 3.7倍
前後無音 0                   0.135s   実時間 5.2倍   ← 採用。20回とも同値
モーラ数依存  1→0.19 / 2→0.22 / 3→0.24 / 4→0.26（既定の無音込み）
              切片 0.17 / 傾き 0.023 = 固定オーバーヘッド支配
CPU使用率     793%（8コア飽和）→ プロセス並列で速くならない
```

発話の間隔が 1〜3秒なら余裕（占有率 8〜24%）。
⚠️ 加速したい場合は GPU 以外に手がない（バッチは禁止、並列は CPU 飽和済み）。

## 4. 加速時の代替（サブPC / 2070S）

同一 LAN 上に CUDA ビルドの ENGINE 0.25.1 がある。切り替え可能であることを実測で確認。

```
同一 AudioQuery で CPU 版と GPU 版の波形を比較
  長さ    21248 / 21248 サンプル（完全一致）
  最大差  9.155e-05（16bit で 3 LSB 相当）
  SNR     75.9 dB
```

メルスペクトログラムに落とせば完全に埋もれる。
→ 人がいない区間は GPU、人が相手をする区間は CPU、という使い分けができる。

🔴 **加速するなら、「秒」で書いた定数を「歩数」か「発話回数」で書く。**
壁時計の秒で書くと、加速した瞬間に一部の時間だけが相対的に遅くなり、時間の比が崩れる。

✅ **加速は音を変えない。**VOICEVOX が返すのはサンプル列で、何秒かけて作っても中身は同じ。
物理スピーカー・物理マイクを使わないので、音が壁時計の時間から切れている。
