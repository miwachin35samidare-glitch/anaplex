- 【ヒト】声の道は2つで大人にも残る：辺縁系 → PAG ＝ 泣き・笑い（生まれつき）／ 喉頭運動野 ＝ 意図して話す（Ackermann・Hage・Ziegler 2014）・前頭弁蓋の両側病変で意図して話せないのに笑い・泣きは出る（Foix-Chavany-Marie）（前の資料）
