```
なるべくシンプルなデフォルメモデル。脳のデフォルメ、新しいカタチ
部品     予測誤差のニューロン ／ 記憶のシナプス
領野     繋ぐ先ごとに作る（視覚の領野、聴覚の領野 …）。領野間も繋ぐ
```

```
          ⚠️ ヒトの一次聴覚野の発火の時定数の直接の実測は無い（前頭・辺縁系しか記録が無い）

          網の中の出来事（誤差の多さ・発火の量）で PC の負荷・温度が変わる → 入れる

          PC の体との対応の候補：温度・負荷・ファンの回転 ↔ 神経修飾物質
```
