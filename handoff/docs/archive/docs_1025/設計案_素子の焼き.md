# 設計案：素子に撃ち方の型を焼く（2026-10-20〜）

【み】10-20 20:01「まぁそれでやってみよう」（引き継ぎ_版93 §20）
- 撃ち方の型（自分で撃つ・はじけ・リズム・撃ったあとの下がり）は外付けの仕組みでなく、素子（焼いた小さな網）に焼く
- 焼く的は、その部位の人のニューロンの自然な状態の列。人が無ければ霊長類
- 焼く形（今の素子と同じ）：入力 ＝ 自分の発火の残り（τ 1〜128歩の8本）、出す ＝ 次の歩に撃つ見込み。列は 1歩 10.67ms に区切る
- 焼いたあと確かめる：間隔の分布・CV・はじけの割合が人の列と合うか（09-11 の教訓：直前だけで次が決まる列は記憶なしでも当たる）

## 0 範囲（10-20 20:39【み】「いや、皮質はもう動いてるでしょ」「全部作り直すってことじゃなくて」）
- 作り直すのは、挙動の違う型だけ。皮質・海馬・上丘（積分して撃つ）は今の素子のまま
- 対象：視床（中継・背内側視床・CL：はじけ ⇔ 撃ち続け）／ 視床下核（不規則・はじけ）／ 黒質（自分のリズム＋跳ね）／
  境・外側手綱核・吻内側被蓋核（自分で撃つ）／ 版95 の淡蒼球・網様部（自分で速く撃ち続ける）
- ⟲ 10-20 20:10 に「皮質・海馬で先に焼いて試す」を勧めたのは範囲の取り違え
- 【み】10-20 20:43「側坐核って基底核の一部だよね？」「それは一つに組んで」
  ⇒ 側坐核（腹側の線条体）は皮質の型の領野のまま残さず、線条体（尾状核・被殻）と一つの線条体の型として基底核と一緒に組む（版95）
  ⟲ 20:39 の範囲で側坐核を「今の素子のまま」に入れたのは誤り（10-16 22:21 の照らしで「側坐核の同じ型も人とずれている」と記録済み）
  ⇒ 組む順の版94（線条体の型・側坐核をこの型へ）と版95（背側の線条体・外節・内節・網様部・視床下核）は一つにまとめる
