## 1 人の形（調べて分かったこと）

```
起きているあいだの皮質の自発の発火 ＝ 皮質の網の中の繋がり ＋ 皮質下から上がる入力
  【ヒト】切片の錐体は入力なしでは撃たない（静止 −72〜−76mV、閾値まで約16mV。Molnár 2008・Nat Commun 2024・Hunt 2023）
  【ヒト】半球離断（子ども10人、手術後6〜35か月）：皮質下から切り離された皮質は、起きていても眠りの徐波が続く。
         左右の繋がりだけ切れた反対の半球は遅くならない ⇒ 支えているのは皮質下（視床・脳幹）からの入力
  【ヒト】Fischer 2016（36人）：橋の吻側背外側被蓋の小さな病変で昏睡（12人中10人）
  【ヒト】Edlow 2012（脳3つ）：脳幹の覚醒の核 → 視床・視床下部・前脳基底部 の道が人にある
  【ヒト】Schiff 2007（1人）：視床の中心の刺激で最小意識から行動が戻る
  【マカク】Redinbaugh 2020：麻酔下で中心外側核（CL）を 50Hz で刺激すると起きる。効くのは皮質の深い層
道の値
  【ヒト】視床の中心の1体の率（Wang 2025、意識障害 29人・麻酔を止めて30分）：CL 約11Hz ／ CM/Pf 約8.5Hz（VL 約13Hz）
         ⚠️ 意識障害の人の値。健康な起きている人はこれより高い側と見込む【見】
  【ヒト】脚橋被蓋核（橋の被蓋の核の1つ）23.2 ± 15.6Hz（JNNP 2010、パーキンソン症候群 4人。起きていたか不明）
  【リスザル】髄板内核 → 皮質：V層（17野）・V/VI層の境（18・19野）、後頭葉全体で I層にも広く
人・霊長類で決まっていないこと
  視床の中心 → 皮質の1体あたりの本数 ／ 健康な起きている人の視床の中心の率 ／ 脳幹の核 → 視床の中心の本数
```

## 2 今の模型【コード】

```
自発     細胞ごとの くじ（皮質 0.3Hz・海馬 0.5Hz）。撃ち方の外で足す（rep ＝ max(撃ち方, くじ)）⇒ 抑制で割られない
         出どころ：Paulk の RS 0.3Hz（3人中2人が麻酔）か出所なし（10-02 の記録）【C・ノブ】
脳幹     状態（起きている／N3／REM）と、覚醒で閾値を下げる倍率（青斑核の率に比例、【ラット】3.4mV ÷【ヒト】16mV）
         撃つ入力としては、皮質にも視床にも届けていない
視床     聴覚の中継（MGB）だけ。背内側視床は下からの入力が 0（直す順 4、別の問い）
```

## 3 案（足すもの）

```
A 視床の中心（CL・CM/Pf にあたる）を領野として足す
  体の作り：視床の中継と同じ（時間細胞を持たない・中継どうしの興奮なし＝版61 の形）
  率の的：起きているあいだ 1体 約8〜11Hz（【ヒト】Wang 2025 の値を下限として）⇒ 1歩 約9〜12%
  入力：脳幹の覚醒（橋の被蓋）から。起きている／N3／REM で変わる
    A1 脳幹の核を撃つ送り手として置く（脚橋被蓋核の【ヒト】23Hz を使う。状態で率を変える）
    A2 今の脳幹の状態から、視床の中心の撃つ確率を直に決める（脳幹の体は置かない）【C】
B 視床の中心 → 皮質（全部の皮質の領野）
  受け方：決めること（4-1）
  本数：人・霊長類の値なし ⇒ ノブ
C 皮質の自発のくじを外す（A・B が入ったら）
  海馬・視床（中継）・背内側視床などのくじは、この案では触らない（人の根拠を別に調べる）
```

## 4 決めること【み】

```
4-1 視床の中心からの入力を皮質でどう受けるか（【リスザル】V層と I層の両方に届く）
    ア 撃たせる側（V層：細胞体の近く）だけ
    イ 調整する側（I層：遠い樹状突起。予測 p に入るが撃たせない）だけ ⇒ 自発の発火は出ない
    ウ 両方（体ごとに本数を分ける。割合は人から出ない ⇒ ノブ）
    ⚠️ 自発の発火（撃つこと）の元にするには、撃たせる側が要る（ア か ウ）
4-2 脳幹の側：A1（核を置く）か A2（状態から直に）か
4-3 本数のノブを何に合わせるか
    候補：無音のあいだの皮質の率を、起きている人の率（錐体 2.6〜3.3Hz、LVQ 2016・Verma 2024）に
         ⚠️ ノブの値を人の率に合わせるのは、ノブ自体が周転円でなければよい【み】10-12
4-4 体数（視床の中心の体を何体置くか）：人の体数を模型の縮尺に直せない ⇒ ノブ（ハードの制約側）
```

## 6 決めることを人で調べ直した（10-12 11時15分【み】「決めてほしいことを人で調べ直して」）

```
4-1 皮質でどう受けるか
  【ヒト】視床の Ca 結合蛋白の染め分け（Münkle 2000 J Chem Neuroanat、引用で読んだ）：髄板内核の多くは calbindin・calretinin、CM だけ parvalbumin
  【ヒト】Allen の人の脳の遺伝子の地図（Müller 2020 bioRxiv、視床 2,305点）：CALB1（matrix）／PVALB（core）の比 ⇒ 髄板内核は matrix が主（一般の記述）
  【マカク】Jones 1998（主にサル）：matrix（calbindin）細胞 ⇒ 皮質の浅い層（I・II・おそらく III の上）へ広く、領野の境を越えて
            core（parvalbumin）細胞 ⇒ 中の層（III〜IV）へ、1つの領野に限って
            CL は calbindin が主 ／ CM・Pf は parvalbumin が主で calbindin ほぼ無し ／ 髄板内核の細胞の大半は皮質でなく線条体へ
  【マカク】Redinbaugh 2020：CL の刺激で効くのは深い層（V層の錐体は頂上の樹状突起を I層へ伸ばす）
  人で測られていないこと：人の髄板内核の線維が皮質のどの層で終わるか（人では線維をたどれない）
  ⇒ 皮質へ覚醒を運ぶのは主に CL（matrix）、届くのは浅い層（I〜III上）【マカク】、人の CL も matrix 型【ヒト・染め分け】
    模型の表現の体は L2/3 の錐体の値（閾値 Hunt 2023 L2/3）。II・III層の入力は L2/3 の錐体の細胞体の近く（撃たせる側）、I層は遠い樹状突起（調整する側）【C の対応】
4-2 脳幹の側
  【ヒト】脚橋被蓋核 23.2 ± 15.6Hz（パーキンソン症候群 4人、状態不明）。起きている／眠りで単一細胞の率がどう変わるかの人の値は見つけていない（脳深部の局所の電位だけ）
  ⇒ A1（核を置く）にすると、状態ごとの率は人から出ない
4-3 本数のノブを何に合わせるか（合わせ先の人の値）
  【ヒト】起きている錐体 2.6Hz（LVQ 2016、中側頭回 II/III層）・3.3Hz（Verma 2024）／ 聴覚野の音の無いとき 3.7Hz（Howard 1996、1人）
4-4 体数
  【ヒト】髄板内核の細胞の数（立体計測）は見つけていない（ラットの Pf 約3万）⇒ 人から出ない
```
